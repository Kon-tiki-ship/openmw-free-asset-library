# Releases

This directory contains only this README in the GitHub repository.
The Version 2 runtime archive is distributed separately through the
[v2 GitHub release](https://github.com/Kon-tiki-ship/openmw-free-asset-library/releases/tag/v2).

For installation and package contents, see the [main README](../README.md#quick-installation).
The two English record catalogs are in [../docs](../docs/); license texts and notices are in
[../LICENSES.md](../LICENSES.md) and [../provenance](../provenance/).

Download `OpenMW_Free_Asset_Library_v2.zip` and its `.sha256` checksum from that
release. The `.omwgame`, `.omwaddon`, `meshes`, `textures`,
`icons`, `sound`, and ZIP files are not committed to Git. In the archive, runtime
files belong inside `Data Files`. The archive also includes both catalogs,
the main README, license texts and provenance notices.
Quarantine files, backups, private workbooks and Git metadata are excluded.
