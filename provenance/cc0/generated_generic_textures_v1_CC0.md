Official CC0 legal text: https://creativecommons.org/publicdomain/zero/1.0/legalcode

These textures were generated individually using the AI-assisted image_gen tool under Furkan Yaşar's instructions. No Bethesda/Morrowind images were supplied to the generation tool as references. The PNG source files were stored in the generated_generic_textures_v1 authoring directory; the DDS versions were created from those sources through resizing, DXT compression, and mipmap export.

File list and SHA-256 hashes: generated_generic_textures_v1_manifest.json.

The scope covers only the new textures. It does not change the licenses of the existing NIF models or records they are linked to, third-party images, or quarantined Bethesda assets. Legacy names were retained only for matching purposes and do not claim that the new textures originated from Bethesda. No guarantee is made regarding the copyright status of AI-generated material.

This package is an initial integration trial. UV alignment of the armor/arrow atlases, seams in repeating wood textures, effect edges, and in-game appearance require separate testing.
