# Ultima LTEX CC0 Confirmation

On 7 October 2026, Furkan Yaşar stated that he had previously verified the CC0 information for the 81 LTEX records linked to Ultima textures in the workbook and explicitly approved retaining them.

The `License` field for these records was retained as CC0; the previous `UNRESOLVED` package status was changed to `CC0_CONFIRMED_BY_USER`. This documents the user's confirmation, not independent verification of a rightsholder's document during that review. The previous source and package information was preserved.

The 4 OpenMW LTEX records were retained under CC0, and the 524 0 A.D. LTEX records under CC-BY-SA-3.0. The 0 A.D. license notice is in `../licenses/0ad_terrain_LICENSE.txt`.
